# Projection Overlap Report: Absolute vs Relative Ranking

*Generated 2026-02-19 03:14*

## Methodology

For each (model, entity) pair we compute how much the **top/bottom 50%** of entity samples changes when switching from **absolute projection** (raw entity value) to **relative projection** (entity minus matched clean sample).

**Steps:**

1. Load entity and filtered-clean projection files (fall back to unfiltered clean if filtered does not exist)
2. Intersect by exact user prompt text so both sets have the same N samples
3. For each layer, compute:
   - **Absolute projection**: entity sample's raw `response_avg_diff` projection value
   - **Relative projection (diff)**: `entity_proj - clean_proj`
4. Split each ranking at the median into top 50% and bottom 50%
5. Overlap % = |intersection| / (N/2) * 100

**Interpretation:** 100% means the clean baseline does not change the ranking at all. 50% means the two rankings are essentially uncorrelated.
